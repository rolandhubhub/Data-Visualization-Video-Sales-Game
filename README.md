# Video Game Sales Data Visualization

## Deskripsi Proyek
Proyek ini bertujuan untuk menganalisis data penjualan video game menggunakan teknik Data Visualization. Visualisasi digunakan untuk memahami pola penjualan berdasarkan platform, tahun rilis, wilayah, judul game, dan genre.

## Tujuan
- Mengidentifikasi platform dengan total penjualan global tertinggi.
- Menganalisis tren penjualan berdasarkan tahun rilis game.
- Membandingkan penjualan di berbagai wilayah.
- Menemukan game dengan penjualan global tertinggi.
- Mengetahui genre dengan total penjualan global tertinggi.

## Dataset
Dataset yang digunakan adalah Video Game Sales, dengan file `vgsales_clean.csv`.

Dataset memuat informasi seperti nama game, platform, tahun rilis, genre, publisher, serta penjualan di Amerika Utara, Eropa, Jepang, wilayah lainnya, dan secara global.

Sumber dataset: https://zenodo.org/records/5898311

## Tools dan Library
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Squarify

## Tahapan Analisis
1. Memuat dan memeriksa dataset.
2. Menyiapkan data untuk visualisasi.
3. Membuat visualisasi penjualan berdasarkan platform.
4. Menganalisis penjualan berdasarkan tahun rilis.
5. Membandingkan penjualan berdasarkan wilayah.
6. Menampilkan 10 game dengan penjualan global tertinggi.
7. Menganalisis penjualan berdasarkan genre.
8. Menyusun ringkasan dan kesimpulan.

## Hasil Visualisasi
Hasil analisis disajikan dalam lima grafik:
1. Horizontal Bar Chart — penjualan berdasarkan platform.
2. Line Chart — penjualan berdasarkan tahun rilis.
3. Donut Chart — distribusi penjualan per wilayah.
4. Lollipop Chart — 10 game dengan penjualan global tertinggi.
5. Treemap — penjualan berdasarkan genre.

Grafik hasil analisis tersedia pada folder `visualizations/`.

## Kesimpulan
Visualisasi data digunakan untuk membantu memahami karakteristik penjualan video game melalui perbandingan kategori dan pola penjualan dalam dataset. Kesimpulan akhir didasarkan pada hasil analisis dan grafik yang dihasilkan.
